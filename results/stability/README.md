# 三次补充实验：模型决策稳定性

本目录来自 2026-10-27 补充实验包。原始运行编号 02、03、04 对应补充第 1、2、3 次，**统计样本量 n=3，不把首次主实验并入均值和标准差**。

## 结果

| 补充次数（原始编号） | 去重 | 评分策略 | 大小策略 | 聚类记录数 | 保留率 | k | 轮廓系数 | DB |
| --- | --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| 1（02） | 是 | drop | drop | 7,424 | 68.48% | 4 | 0.344117 | 1.107673 |
| 2（03） | 是 | drop | drop | 7,424 | 68.48% | 4 | 0.344117 | 1.107673 |
| 3（04） | 是 | drop | category_median | 8,892 | 82.02% | 3 | 0.366450 | 1.068732 |

去重和评分决策 3/3 一致，大小决策出现两种选择。三字段策略组合仅补充第 3 次与首次主实验相同（1/3）；这里的“完整计划频次”按三个策略字段统计，不要求理由文字逐字一致。

轮廓系数均值为 **0.351561**，样本标准差为 **0.012894**；DB 均值 **1.094693**，样本标准差 **0.022483**；保留率样本标准差为 **7.8180 个百分点**。均采用 `ddof=1`，只描述这三次调用，不能推广为模型总体稳定性。

三次分别使用 1,367、1,348、1,362 tokens，合计 4,077；加上首次的 1,412，共四次调用、5,489 tokens。实际账单费用未知。每次调用响应 ID 不同，均一次通过，无重试。

## 能说明什么

可观察的输入数据、核心代码、请求参数和依赖一致，输出策略仍可能变化；服务端模型内部版本未知，也没有显式固定模型生成随机种子或温度。

补充 1 与 2 的原生分群 ARI 为 1；与补充 3 在共同记录上的 ARI 约为 0.724047，样本集合 Jaccard 约为 0.834908。共同完整记录固定 7,424 条、`k=4` 再比较时，ARI 都为 1。三组两两比较互相依赖，不能当作三个独立统计样本。

补充 3 的大小处理理由先说“不适合用中位数填充”，随后又选择类别中位数。结构验证接受的 JSON 是 `category_median`，本地工具按该值执行；这暴露了理由的语义一致性问题。

上述实验测量策略与分群变化，**没有检验填补误差**。人工复核完成也不等同于对未知真实评分/大小的准确性验证。
