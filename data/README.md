# 数据来源与许可

使用 Kaggle 的 [Google Play Store Apps](https://www.kaggle.com/datasets/lava18/google-play-store-apps)，发布者 Lavanya / lava18，获取日期为 2026-10-24。仅使用 [raw/googleplaystore.csv](raw/googleplaystore.csv)，共 10,841 条、13 列，原始文件未改动；未合并评论数据表。

这是历史采集快照，下载日期不等于采集日期，不代表 2026 年实时商店情况。一行是一次采集记录，`App` 名称不是经过验证的唯一标识符。
